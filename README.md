# FREQUENCY 13 UFO Console

Shareable web app for the 13 Galactic Tones with deep transmissions, effects (delay, LFO, reverb), vertical faders, color controls, Read Aloud, and Share.

## Live Site (no login needed)

Once GitHub Pages is enabled:
https://danaedward406-sketch.github.io/frequency13-ufo-console/

## Enable Pages
1. Go to the repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / (root)
4. Save

The original grid image (original-frequency13-grid.jpg) should be uploaded to the repo root so social shares show the chart.

Click any symbol for the deep meaning + channeling notes. Font is Inked Skin. Colors are adjustable at the bottom.

No login required for anyone to use or share the app.
